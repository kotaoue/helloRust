# hello_tauri

This is a simple Hello World desktop application built with the [Tauri](https://tauri.app/) framework.

## Prerequisites

Install the system dependencies for your platform by following the [Tauri prerequisites guide](https://v2.tauri.app/start/prerequisites/), then install Rust.

## Usage

```sh
cd hello_tauri
cargo run
```

The command opens a desktop window displaying “Hello, World!”.
