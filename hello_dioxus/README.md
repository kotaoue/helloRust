# hello_dioxus

This is a simple Hello World application built with the [Dioxus](https://dioxuslabs.com/) framework.

## Prerequisites

```sh
brew install rustup
rustup default stable
rustup target add wasm32-unknown-unknown
cargo install dioxus-cli
```

## Usage

```sh
cd hello_dioxus
dx serve --platform web
```
