# hello_dioxus

This is a simple Hello World application built with the [Dioxus](https://dioxuslabs.com/) framework.

## Usage

```sh
cd hello_dioxus
cargo run
```

Expected output:

```sh
<h1>Hello, World!</h1><p>This is a simple Dioxus application.</p>
```
