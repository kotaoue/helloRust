# hello_warp

This is a simple Hello World web application built with the [Warp](https://github.com/seanmonstar/warp) framework.

## Usage

```sh
cd hello_warp
cargo run
```

Once the server is running, open your browser or use `curl` to access it:

```sh
curl http://127.0.0.1:3030/
```

```sh
curl http://127.0.0.1:3030/sing
```

```sh
curl http://127.0.0.1:3030/json
```
